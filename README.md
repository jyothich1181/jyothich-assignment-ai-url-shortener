# Agentic SDLC Prototype (Java 21 / Spring Boot 3)

An autonomous, human-in-the-loop Software Development Life Cycle (SDLC) agent built with Python, the Google GenAI SDK (`gemini-2.5-flash`), and Docker. Given an engineering requirement, the agent analyzes ambiguities, proposes a structured implementation plan, waits for human approval, generates Java 21 / Spring Boot 3 code and JUnit 5 tests, and iteratively self-heals until `mvn test` passes.

> **Looking for the generated Spring Boot URL Shortener documentation?**  
> See [`workspace/README.md`](workspace/README.md) for API endpoints, `curl` examples, validation rules, and Maven commands.

## 4-Phase Agentic Workflow

1. **Phase 1 — Planner Agent:** Inspects existing files in `/app/workspace`, identifies ambiguities, documents explicit engineering assumptions, and writes `workspace/PLAN.md`.
2. **Phase 2 — Controlled Autonomy (Human Gate):** Pauses execution and requires explicit human sign-off (`y/n`) before any source code is written or modified.
3. **Phase 3 — Autonomous Builder:** Uses function calling (`list_files`, `read_file`, `write_file`) to implement layered Spring Boot components and JUnit 5 / MockMvc tests.
4. **Phase 4 — Self-Healing Verifier:** Executes `run_maven_tests` (`mvn test -B`). If compilation or test assertions fail, the agent reads the stack trace, patches the code, and re-runs tests until `TEST STATUS: SUCCESS`, then writes `workspace/WALKTHROUGH.md`.

## Quick Start

### 1. Build the Docker Image
From the repository root (`agentic-sdlc-java/`):
```bash
docker build -t agentic-sdlc .
```

### 2. Run an Interactive Agent Session
Mount your local `workspace/` directory so generated Java code persists on the host machine:

* **macOS / Linux:**
  ```bash
  docker run -it --rm \
    -e GEMINI_API_KEY="YOUR_GEMINI_API_KEY" \
    -v "\$(pwd)/workspace:/app/workspace" \
    agentic-sdlc
  ```

* **Windows (PowerShell):**
  ```powershell
  docker run -it --rm `
    -e GEMINI_API_KEY="YOUR_GEMINI_API_KEY" `
    -v "${PWD}/workspace:/app/workspace" `
    agentic-sdlc
  ```

* **Windows (Git Bash):**
  ```bash
  MSYS_NO_PATHCONV=1 docker run -it --rm \
    -e GEMINI_API_KEY="YOUR_GEMINI_API_KEY" \
    -v "\$(pwd -W)/workspace:/app/workspace" \
    agentic-sdlc
  ```

## Evaluated Scenarios

* **Scenario 1 (Greenfield Build):** Built the initial Spring Boot URL shortener with Base62 short-code generation, `POST` shorten endpoint, `302` redirect endpoint, H2 persistence, and MockMvc tests.
* **Scenario 2 (Brownfield Analytics):** Extended the existing entity, service, and controller to track `totalClicks` and `lastAccessedAt` on every redirect, plus added a `GET` analytics stats endpoint.
* **Scenario 3 (Deduplication, Validation & Docs):** Added idempotent URL deduplication (returning the existing short code for duplicate long URLs), strict HTTP/HTTPS input validation (`400 Bad Request` on invalid URLs), and generated [`workspace/README.md`](workspace/README.md).
